# 함께 공부(공부시간 공유)

작성일 2026-11-19

## 기능

화면 오른쪽 아래 `함께 공부` 버튼을 열어 `공부 시작`을 누르면, 오늘 공부시간이 접속 중인 다른 학습자에게 표시됩니다. 필기·실기 어느 화면으로 이동해도 계속 켜져 있습니다.

- 표시 항목: 닉네임, 공부 중/멈춤, 오늘 공부시간
- 기준 날짜: 한국 시간. 자정에 0으로 돌아갑니다.
- 접속 판정: 최근 60초 안에 신호를 보낸 사람만 목록에 나옵니다. 브라우저는 20초마다 신호를 보냅니다.
- 창을 닫거나 기기가 잠들어 5분 넘게 기록이 끊기면 그 구간은 공부시간에서 뺍니다.
- 닉네임은 자동으로 정해집니다. 형식은 `3계층 라우터 27`처럼 "OSI 계층 + 그 계층의 용어 + 두 자리 숫자"입니다. `다른 닉네임` 버튼으로 다시 뽑을 수 있고, 공부 중에는 바꿀 수 없습니다.
- 직접 지은 닉네임은 쓸 수 없습니다. 서버도 이 형식이 아닌 이름은 저장하지 않습니다.
- 용어 목록은 `src/study-room-model.mjs`의 `LAYER_TERMS`에 있습니다. 목록을 바꾸면 `supabase/study-room.sql`의 형식 검사도 같이 바꾸고 SQL을 다시 실행해야 합니다. 두 곳이 다르면 테스트가 실패합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `src/study-room-model.mjs` | 타이머 계산, 저장 값 검증, 목록 정렬 |
| `src/StudyRoom.jsx`, `src/study-room.css` | 화면 |
| `supabase/study-room.sql` | DB 표와 함수 |
| `.env.production` | 배포용 연결 주소와 공개 키 |
| `scripts/study-room-mock.mjs` | 로컬 확인용 가짜 서버 |
| `tests/study-room-model.test.mjs` | 모델 테스트 |

별도 라이브러리 없이 브라우저 `fetch`로 Supabase 함수 `study_beat` 하나만 호출합니다. 연결 값 두 개가 없으면 버튼 자체가 화면에 나오지 않습니다.

## 저장되는 정보

- 서버: 무작위 기기 식별자, 닉네임, 날짜, 오늘 공부 초, 공부 중 여부, 마지막 신호 시각. 7일이 지난 행은 지웁니다.
- 브라우저: 같은 내용을 `na2-study:room:v1` 키로 보관합니다.
- 로그인, 실명, 학번, 이메일은 받지 않습니다.

## 보호 장치와 한계

- 표에는 직접 접근할 수 없고 함수로만 읽고 씁니다. 목록에는 기기 식별자 대신 짧은 해시만 내려보내므로 다른 사람의 기록을 덮어쓸 수 없습니다.
- 서버가 공부시간을 제한합니다. 오늘 0시부터 흐른 시간보다 길 수 없고, 지난 신호 이후 실제로 흐른 시간만큼만 늘어납니다.
- 로그인이 없으므로 타이머만 켜 두는 행동은 막지 못합니다. 성적이나 출석 근거로 쓰지 않습니다.
- Supabase 무료 요금제는 7일 동안 요청이 없으면 프로젝트를 일시 정지합니다. 정지되면 대시보드에서 다시 켭니다. 그동안에도 각자의 공부시간은 브라우저에 기록되고 목록만 보이지 않습니다.

## 처음 설정

1. Supabase 대시보드 > SQL Editor에 `supabase/study-room.sql` 전체를 붙여 넣고 Run을 누릅니다.
2. `.env.production`에 Project URL과 Publishable key를 적습니다. Secret key와 DB 비밀번호는 저장소에 넣지 않습니다.
3. `main`에 푸시하면 GitHub Actions가 빌드해 배포합니다.

## 로컬 확인

```
copy .env.example .env.development.local
node scripts/study-room-mock.mjs --demo
npm run dev
```

## 스터디카페(3D) · 2026-11-19 추가

`함께 공부` 창의 `스터디카페 보기`를 누르면 전체 화면으로 3D 공간이 열립니다. 좌석 10개, 책장 옆 케이블링 실습대, 오른쪽 탕비실로 구성합니다.

- 캐릭터: 카피바라·고양이·곰·토끼·햄스터·병아리 여섯 종류의 자체 도안입니다. 종류와 색은 참가자마다 자동으로 정해집니다.
- 이동: 바닥을 누르거나 방향키(WASD)로 걷습니다. 가구는 돌아서 갑니다.
- 자리: 빈 자리를 누르면 그 자리에 앉아 공부를 시작합니다. 자리를 뜨면 공부시간이 멈추고, 내 자리를 다시 누르거나 `이어서 공부`를 누르면 돌아가 앉습니다.
- 만석: 10석이 모두 차면 서버가 자리를 주지 않고 "자리가 모두 찼습니다" 안내가 나옵니다. 멈춘 지 10분이 지나면 자리를 반납합니다.
- 실시간 이동 공유: Trystero로 참가자 브라우저끼리 직접 연결(WebRTC)해 걷는 위치만 주고받습니다. 닉네임·좌석·공부시간은 계속 서버 함수가 맡습니다.

| 파일 | 역할 |
|---|---|
| `src/study-cafe-map.mjs` | 좌석 위치, 가구 영역, 길찾기, 받은 위치 검사 |
| `src/study-scene.js` | three 장면과 캐릭터, 조작 |
| `src/StudyScene.jsx` | 화면 연결. three와 Trystero는 이 화면을 열 때만 내려받음 |
| `src/study-net.js` | Trystero 연결 |

알아 둘 점입니다.

- 직접 연결 방식이므로 같은 시간에 스터디카페 화면을 연 참가자끼리는 기술적으로 서로의 IP 주소를 알 수 있습니다. 화면에는 표시하지 않습니다.
- 직접 연결을 막는 네트워크에서는 다른 사람의 걷는 모습이 보이지 않고, 자리에 앉은 모습으로만 보입니다. 좌석과 공부시간은 그대로 보입니다.
- 처음 연결을 맺을 때 외부 공개 중계 서버(Nostr)를 씁니다. 일부 중계 서버가 응답하지 않아도 나머지로 연결합니다.
- 받은 위치는 형식과 범위를 확인한 뒤에만 쓰며, 서버 목록에 없는 참가자의 위치는 무시합니다.

### 케이블링 실습대 연습 · 2026-11-19 추가

실습대를 누르면 캐릭터가 그 앞으로 걸어가 랜툴을 쥐는 동작을 하고, 위에 케이블 제작 순서 안내판이 뜹니다. 안내판은 T568B 기준으로 피복 벗기기, 순서로 펴기, 끝 자르기, 커넥터에 끼우기, 압착하기, 테스터 확인의 여섯 단계를 차례로 보여 줍니다. 색 순서는 실기 모듈(`src/modules/cabling/content.mjs`)과 같습니다. 다른 참가자가 연습 중일 때도 같은 안내판이 보입니다. 화면 왼쪽 위 `케이블링 훈련 열기`를 누르면 실제 훈련 화면(`#/cabling`)으로 이동합니다. 실습대에서 연습하는 시간은 공부시간에 포함합니다. 실기만 준비하는 학습자를 위한 것이며, 실습대에 도착하면 타이머가 켜지고 실습대를 떠나면 멈춥니다. 자리가 없던 학습자는 이때 빈 자리를 하나 배정받습니다.
